ilmmind — SQLite Cache Schema

The relational model materialised in the local SQLite cache. Raw JSON/SVG files remain the source of truth; every table here is rebuilt from those files on each device. Crow's-foot notation: a bar marks the "one" side, a fork marks the "many" side. Dashed edges are optional (nullable) or polymorphic. Core note/ink tables mirror the current codebase; graph, citation, video, AI and sync tables are forward-looking per the project roadmap.

Entity-Relationship Diagram · ilmmind SQLite cache. Grouped by domain: Notes & Ink (mirrors the current codebase), Knowledge Graph & Citations, Video & Transcription, and AI · Search · Sync. Timestamps are stored as epoch-millisecond integers; embeddings and search_index are virtual tables (sqlite-vec / FTS5) that reference content polymorphically via (owner_type, owner_id).
